# Como contribuir

Projeto individual de formação, mas com fluxo de trabalho de equipe.

## Fluxo

1. Pegue uma issue (respeite o campo "Depende de").
2. Crie uma branch a partir da `main`: `feat/12-atestar-titular`, `fix/31-erro-rede`, `docs/2-escopo-juridico`.
3. Faça commits pequenos no padrão Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`.
4. Abra um Pull Request usando o template e referencie a issue (`Closes #1`).
5. Espere a CI ficar verde e mescle.

## Regras

- Nunca commitar chaves privadas, `.env` ou seed phrases.
- Usar uma carteira exclusiva para testes.
- Seguir as regras de linguagem de `docs/ESCOPO_JURIDICO.md`.
